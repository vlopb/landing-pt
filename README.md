# Landing de la Plataforma de Gestión Digital

Frontend de la página de inicio autenticada de la Plataforma de Gestión Digital de la Secretaría de Seguridad Pública Municipal de Ciudad Juárez.

## Estructura rápida

- `resources/pgd/`: todos los archivos propios de la landing (Blade, CSS y JavaScript).
- `docs/`: documentación detallada del proyecto.
- `routes/web.php`: ruta de entrada de Laravel.
- `tests/`: verificaciones automatizadas.

Consulta [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) para instalar, ejecutar y validar el proyecto.
